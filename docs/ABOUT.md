## Overview

A simple 4-joint robot arm running ROS 2 Jazzy with MuJoCo physics simulation.
Built as a learning project for joint-space control, URDF/MJCF workflows,
and getting started with OORB Studio.

## What you'll learn

- How ROS 2 nodes publish and subscribe to joint states
- How MuJoCo MJCF models define robot kinematics and actuators
- How to control a simulated arm with position commands
- How to bridge ROS 2 and browser-based simulation

## Requirements

- **Sim-only**: No hardware needed. Everything runs in the browser.
- **Local dev**: Docker + VS Code (devcontainer provided)
- **OORB Studio**: Just click "Open in Studio"

## Who is this for

Beginners to ROS 2 and robot simulation. If you've never controlled a robot arm
in code before, start here.
